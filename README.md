# 数据科学与城市空间研究

[![Publish online textbook](https://github.com/zipan07/urban-spatial-data-science/actions/workflows/publish.yml/badge.svg)](https://github.com/zipan07/urban-spatial-data-science/actions/workflows/publish.yml)

[![License: CC BY-NC-ND 4.0](https://img.shields.io/badge/License-CC_BY--NC--ND_4.0-bb6857.svg)](https://creativecommons.org/licenses/by-nc-nd/4.0/)

《数据科学与城市空间研究》（Data Science and Urban Spatial Research）中文在线教材，共16章。

**在线阅读：** https://zipan07.github.io/urban-spatial-data-science/

本项目面向城乡规划、地理学、生态学、环境科学与城市科学相关课程，采用 Quarto、Python、Jupyter 与 ArcGIS Pro 构建，围绕“问题—数据—方法—证据—判断—表达”组织教学。V0.11为16章补入城市复杂系统、因果图、FAIR、空间数据质量、换域、GIS数据模型、专题地图、空间统计、网络可达性、空间机器学习、不确定性、规划证据和鲁棒决策等理论单元，并增加统一版权与使用说明。数据目录集中位于全书末尾。

> 当前状态：首轮课堂试用版，内容持续迭代。代码以带文件名、行号和复制按钮的阅读单元嵌入正文；关键实验同时给出结果图、判读路径和规划含义。合并到 `main` 的内容会由 GitHub Actions 自动发布。

数据总览见 [`data/README.md`](data/README.md)，真实开放数据见 [`data/china_city_open/`](data/china_city_open/metadata.json)，生成式练习数据见 [`data/nanjing_teaching/`](data/nanjing_teaching/README.md)。章节配额、案例方向、图表计划与版权规则见 [`EDITORIAL_ROADMAP.md`](EDITORIAL_ROADMAP.md)。
