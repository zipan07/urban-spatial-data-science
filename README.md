# 数据科学与城市空间研究

[![Publish online textbook](https://github.com/zipan07/urban-spatial-data-science/actions/workflows/publish.yml/badge.svg)](https://github.com/zipan07/urban-spatial-data-science/actions/workflows/publish.yml)

《数据科学与城市空间研究》（Data Science and Urban Spatial Research）中文在线教材，共16章。

**在线阅读：** https://zipan07.github.io/urban-spatial-data-science/

本项目面向城乡规划硕士课程，采用 Quarto、Python、Jupyter 与 ArcGIS Pro 构建，围绕“问题—数据—方法—证据—判断—表达”组织教学。V0.7 将书稿目标调整为30万字，并重点补齐Miniconda、Conda环境、VS Code、Jupyter内核、ArcGIS Pro环境以及Pandas、GeoPandas上机操作。当前教材已形成123组嵌入式代码示例。

> 当前状态：首轮课堂试用版，内容持续迭代。代码以带文件名、行号和复制按钮的阅读单元嵌入正文；合并到 `main` 的内容会由 GitHub Actions 自动发布。

十倍扩写的章节配额、案例方向、图表计划与版权规则见 [`EDITORIAL_ROADMAP.md`](EDITORIAL_ROADMAP.md)。
